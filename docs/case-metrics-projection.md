## 默认有效视图

Case 列表默认读取当前有效证据。若正式任务报告显式引用恢复归档，读取并核验报告及归档后，按 dataset + sample + attempt 投影评分和统计字段，不更新原始 Case、原始证据对象或历史哈希。不按最近时间猜测修订版本。

原始历史值仍可通过“原始归档（历史记录）”查看，API 参数 evidence_version=original；默认参数为 current。证据详情同时返回有效指标、恢复来源及原始证据哈希，原证据内容不改写。

## 全部代码差异审查

- 保持一任务一报告，数据集独立成绩 / 基线，恢复修订可追溯且幂等。
- 保留原失败事件；恢复完成追加事件并更新当前投影；Case 和历史证据不覆盖。
- 远程大结果使用安全引用的命令与唯一临时文件、0600 权限和防覆盖写入，再经 SFTP 有界读取。
- 长归档持续心跳，清理等待任务，心跳异常不被静默吞掉。
- 先为全部 Case 预留评分文件，再使用剩余额度携带轨迹；小任务继续自动导入 Trace，大轨迹保留远端路径与哈希，不挤掉其他样本评分。

- 多数据集日志查询必须显式选择数据集；原始 / 恢复 Case 关联同一原尝试与 Trace。
- 保持旧报告 Lite 范围兼容；未知比较条件按记录隔离，不宣称严格可比。
