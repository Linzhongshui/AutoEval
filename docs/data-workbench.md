# 数据工作台

新增“标准仓输入”页签，提供标准版本同步、离线导入、模型映射和启动配置补全；它与榜单录入、配置审批独立，不执行测评。详见[标准输入接入](./standard-inputs.md)。

开发环境入口：`#data-workbench`。菜单名为“数据工作台”，延用紫色主题、页签、表格和详情抽屉。

## 范围

- 报告评审入榜：从报告目录提名，待评审后批准或驳回。提名、批准以及展示榜单时均核验原始报告证据；只接受真实且完整的 GPQA Lite 报告，模型、成绩、条件和校验值不得改写。
- 榜单数据维护：支持人工及官方来源，记录模型、数据集、指标、单位、方向、范围、比较条件、来源网址、版本和 SHA-256。不要求存在平台报告。
- 官方数据导入：支持 JSON 文件或文本批量录入，每批 1–50 条，文件上限 1MB。上传文件使用其字节 SHA-256，修改文本后需提供原文校验值。按条保存，失败明确告知已保存数量；相同来源键和内容重复导入不新增记录，不同内容返回冲突。
- 模型与数据集列表：汇总已登记及榜单记录中的身份、来源和可用元数据，提供搜索及分页。模型采用 ModelScope 格式标识；隐藏部分测试模型仅影响前端显示，不删除历史引用。
- 环境诊断：原 Docker 诊断入口统一移至此页，不再散落业务页面。

页面没有通用官网自动抓取或定时任务；仓库 `backend/scripts/` 已有定向官方来源导入及元数据补录脚本，部分脚本会直接调用批准接口，必须先审阅，不能作为只读操作运行。来源网址与校验值由录入者提供，不能据此宣称已自动核验官方身份；原文文件需由录入者保管，本轮仅持久化结构化成绩、来源及原文校验值。后续自动同步应通过明确来源的适配器生成相同待评审记录。

## 数据与评审

新增 `leaderboard_record`，数据库迁移 `0022_leaderboard_curation`。开发库已执行迁移，其他环境先在 `backend/` 执行 `uv run alembic upgrade head`。

状态流转：待评审 → 已批准 / 已驳回；已批准 → 已撤回。已驳回或已撤回可修改后重新评审。批准中的记录必须先撤回才能编辑；报告来源重新提名仍锁定原始成绩。修改及评审均通过 `expected_revision` 防止并发覆盖。

每次创建、修改、批准、驳回、撤回均追加 `audit_event`，保存版本、原因及完整内容快照。历史审计不修改、不删除。单团队开发模式主体固定为 `local-operator`，支持同一操作员自审；不等同于正式双人审批或 Release 门禁。

开发版测评榜单默认展示已批准数据；原自动报告排名保留为“平台运行报告候选成绩（未人工评审）”。官方、人工和平台报告按来源及条件独立分组，不混合排名；条件明确未知的记录单独成组。同组同模型展示最近录入且已批准的一条，按指标方向排名，同分同名次。不同来源不计算综合分。前端可进一步把相同数据集和指标的不同来源分组合并为“参考对比”，逐条保留测试范围和条件；此时显示的顺序不是严格同条件排名，不能据此推断 Lite、全量或不同思考模式成绩等价。

官方榜单录入不自动创建正式门禁基准，不回写报告、不触发模型请求。生产前端不包含工作台及诊断控件，后端操作接口也限制在 development/test；正式身份、角色授权和生产数据治理另行接入。

## 接口

统一前缀 `/api/autoeval/v1/data-workbench`：

| 接口 | 用途 |
| --- | --- |
| GET `/entries?offset=0&limit=20` | 分页维护列表，返回 next_offset |
| POST `/entries` | 创建待评审记录，source_key 保证重试不重复 |
| POST `/entries/{id}/edit` | expected_revision、entry、reason；成功后回到待评审 |
| POST `/entries/{id}/review` | expected_revision、action（approve/reject/withdraw）、reason |
| GET `/published` | 仅已批准且仍满足证据要求的分组榜单 |

历史使用 `/api/autoeval/v1/audit-events?resource_id={id}`。缺失对象返回 404，非法输入返回 422，来源或版本冲突返回 409，非开发环境返回 403。

官方文件为 EntryInput 数组，可从页面“填入格式模板”获得完整格式。`source_type=official` 必须提供 HTTPS 来源地址及原文 SHA-256；百分比单位使用 `%`、成绩为 0–100，非有限值拒绝。性能成绩需填写独立指标、单位、方向及硬件、并发、输入输出长度等条件，不以总耗时替代性能。
