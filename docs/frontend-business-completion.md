# 前端业务信息补充记录

日期：2026-11-11。沿用原有控制台、配置、任务与报告页面，不新增业务一级菜单。

| 内容 | 入口与行为 |
| --- | --- |
| 提交预检 | 任务摘要检查模型列表、资源环境和配置绑定；分别展示失败原因及管理入口指引，不发送模型生成请求。 |
| 提交确认 | 展示配置版本、资源、样本数、清单及请求上限；预检通过且确认范围后才能提交，修改选择或超过五分钟需重新检查。 |
| 任务列表 | 简短任务标识、中文状态及报告生成状态；从已生成报告直接进入报告详情。 |
| 任务进展 | 显示后台状态对应的执行阶段、事件更新时间、最近查询时间；取消请求与清理状态分开呈现。 |
| 异常恢复 | 查询失败保留旧详情并提示过期；执行失败提供 Case 定位入口；未知结果不引导盲目重发。 |
| 配置快照 | 可读参数、配置版本、清单及工具版本；完整快照、校验值、状态事件及标识复制放抽屉。 |
| 报告可信性 | 独立显示历史覆盖、当前证据、分析和门禁状态；证据不可用时不展示成绩及差值。 |
| Case 回溯 | 按样本查每次尝试、按当前页执行状态筛选；模型输入、响应及完整证据按需进入抽屉，打开时校验。 |
| 基准比较 | 显示基准键及版本、可比性原因；缺失、不可比和证据不可用不填零。 |
| 自动分析 | 总览关键结论和数据集详情可查看分析，区分事实与推断并引用证据；失败按后台允许次数重试，未知结果禁止重发。 |
| 基础状态 | 加载、空数据、查询失败、重新查询及旧状态提示；正常页面不展示 Docker 诊断。 |

- Chrome 浏览器检查任务总览、数据集详情、Case、配置快照，以及报告总览、数据集结果、样本明细和返回路径通过。
- 浏览器使用模拟响应验证预检失败阻止提交、成功仍需确认、选择变化失效；未提交测评或发送生成请求。此项不代表真实模型或 SSH 联调通过。

## 数据边界

预检只检查可确认的范围。Docker 资源预检确认容器环境，原生工具及原始样本证据在提交和执行时再次校验；通用配置规格接口不作为正式执行许可。样本判分通过/未通过数量、耗时等未提供可靠字段时显示缺省值，不从执行成功数推算。

Case 列表的执行成功不代表答对，当前 API 不提供逐样本评分字段，列表不制造正确性筛选；评分结论从已校验报告证据确认。筛选仍为当前页。现存两份历史报告原始对象缺失，布局及异常路径检查不代表有效报告正向验收。没有新增测评或付费模型调用。
