# 桌面响应式布局检查

日期：2026-11-10。浏览器：本机 Chrome Headless。检查方式：真实渲染截图、DOM 尺寸检测与截图复查。

## 范围

| 窗口尺寸 | 实测 CSS 视口 | 结果 |
| --- | --- | --- |
| 1920 × 1080 | 1896 × 981 | 页面布局正常 |
| 1440 × 900 | 1416 × 801 | 页面布局正常，筛选允许换行 |

Chrome 窗口尺寸与 innerWidth/innerHeight 不同，因此同时记录实测 CSS 视口，未将窗口尺寸当作精确 CSS 视口。

覆盖首页、控制台、测试配置、任务列表、任务详情、报告列表、报告总览、精度榜单；额外打开标准配置抽屉和报告数据集结果详情。共 40 个页面/状态与屏幕尺寸组合。

## 发现及修复

1. 中等屏幕任务与报告筛选标签挤压、重叠。筛选项原先可无限收缩，子控件仍有最小宽度。已设置合理伸缩基准，并在 601–1200px 使用两列网格。
2. 中等屏幕控制台双栏导致配置区域和耗时摘要拥挤。已在 601–1200px 改为单栏，保留较宽屏幕原有双栏。
3. 中等屏幕报告列表超出容器宽度，操作列需横向滚动寻找。保留表格内部滚动，固定右侧操作列，增加滚动提示，并保持时间列完整单行。
4. 数据集长名称省略属于既有设计，保留 ellipsis；完整名称通过悬停及完整数据集列表查看，不计作布局缺陷。

## 复查

- 页面根节点未出现整体横向溢出。
- 筛选标签、输入框和选择框不再互相覆盖。
- 报告操作列在中等屏幕可见，其余宽列在表格容器内部滚动，不扩大页面宽度。
- 配置抽屉关闭按钮、树形目录与参数表单在四档尺寸可见。
- 报告数据集详情的返回入口、切换器、结果图表未见越界。
- 页面主标题、卡片、侧栏与导航未见遮挡。
- TypeScript 检查、Vite 生产构建通过。

## 证据与限制

截图和 DOM 诊断保存在本地 `.screenshots/responsive/`。各尺寸 `*-contact.jpg` 为总览；单页 PNG 可查看原始细节。初查后针对筛选、控制台和报告问题重新截图复查。

这是桌面布局专项检查，不等同于所有业务交互、浏览器兼容性和移动端测试。未覆盖所有自定义配置、日志/证据抽屉、所有筛选数据组合与系统缩放比例；未进行浏览器控制台错误的自动采集。报告表格内部横向滚动是保留的响应式行为。
